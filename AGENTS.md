# AGENTS.md

This file provides guidance to coding agents working with code in this repository.

## Build Commands

```bash
make build           # Compile provider binary
make install         # Build and install to $GOPATH/bin
make test            # Run unit tests
make testacc         # Run acceptance tests (requires KEYCARD_* env vars)
make lint            # Run golangci-lint
make fmt             # Format code
make generate        # Generate docs and client code
make generate-client # Regenerate API client from OpenAPI spec
make generate-docs   # Regenerate docs/ via tfplugindocs
```

A bare `make` runs `fmt lint install generate`.

## Testing

Acceptance tests require environment variables:
- `KEYCARD_CLIENT_ID`
- `KEYCARD_CLIENT_SECRET`
- `KEYCARD_ENDPOINT`
- `KEYCARD_TEST_KMS_KEY_1` / `KEYCARD_TEST_KMS_KEY_2` (for encryption tests)

Run single test: `TF_ACC=1 go test -v -run TestAccZoneResource_basic ./internal/provider/`

## Architecture

**OpenAPI-Driven**: The API client (`internal/client/client.gen.go`) is auto-generated from `api/openapi.yaml` using oapi-codegen. Never edit `client.gen.go` directly - modify the OpenAPI spec and run `make generate-client`.

**Key Files**:
- `internal/provider/provider.go` - Provider definition, resource/datasource registration
- `internal/provider/provider_helpers.go` - Shared model mapping between Terraform and API types
- `internal/client/setup.go` - API client initialization with OAuth2 and retry logic
- `configs/oapi/client.yaml` - Code generation configuration

**Resource Pattern**: Each resource follows the same structure:
1. `*_resource.go` - CRUD operations using generated client
2. Uses helpers from `provider_helpers.go` for type conversion
3. Corresponding acceptance tests in `*_test.go`

**Authentication**: OAuth2 client credentials flow with automatic token refresh. Retryable HTTP client handles 429 and 5xx errors.

**Docs**: `docs/` is generated by tfplugindocs (via the `tools/` go module, templates in `templates/`). Never edit `docs/` directly - run `make generate-docs`.

## Code Generation Flow

```
api/openapi.yaml → oapi-codegen → internal/client/client.gen.go
```

When API changes:
1. Update `api/openapi.yaml`
2. Run `make generate-client`
3. Update `provider_helpers.go` mapping functions as needed
4. Update affected resources/data sources

## Local Development

Configure `~/.terraformrc` with dev overrides:
```hcl
provider_installation {
  dev_overrides {
    "keycardai/keycard" = "/path/to/go/bin"
  }
  direct {}
}
```

Then: `make install && cd examples && terraform plan`
